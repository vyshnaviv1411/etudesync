📚 ÉtudeSync

> **A collaborative digital workspace designed to make learning organized, interactive, and engaging.**

ÉtudeSync is a full-stack web application that brings together study collaboration, productivity tools, knowledge sharing, and student engagement into one unified platform. It aims to eliminate the need for switching between multiple applications by providing everything required for an effective learning environment in a single workspace.

---

## ✨ Features

### 🤝 CollabSphere
A collaborative study room where users can:
- Create and join study rooms
- Real-time text chat
- Share files and study materials
- Interactive whiteboard
- Poll creation
- Participant management

### 📖 InfoVault
A centralized knowledge hub for:
- Study resources
- Notes
- Learning materials
- Organized content management

### 🎯 FocusFlow
Designed to improve productivity with:
- Clean distraction-free workspace
- Focus-oriented interface
- Organized study experience

### 🧠 MindPlay
A wellness and engagement module including:
- Digital journal
- Mood tracking
- Mini games
- Student community interactions
- Motivation and engagement tools

### 📝 AccessArena
Interactive assessment module featuring:
- Practice quizzes
- Knowledge evaluation
- Performance improvement

### 👤 User Management
- Secure Registration
- Login Authentication
- Profile Management
- Session Handling

# 💻 Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/EtudeSync.git
```

### 2. Move the project

Copy the project folder into your XAMPP `htdocs` directory.

```
C:\xampp\htdocs\
```

### 3. Start XAMPP

Start:

- Apache
- MySQL

### 4. Create Database

Create a MySQL database named:

```
etudesync
```

### 5. Import Database

Import the provided SQL file into phpMyAdmin.

### 6. Configure Database

Update your database credentials inside:

```
includes/db.php
```

### 7. Run the Project

Open your browser and visit:

```
http://localhost/EtudeSync
```
